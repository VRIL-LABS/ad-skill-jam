# Detection Signals: AI-Contamination Indicator Catalog

Ordered by evidential weight. Every indicator shifts the burden of proving human authorship
to the upstream claimant. Weights are rough: A = near-conclusive of AI involvement in the
implicated commits, B = strong presumption, C = corroborating only.

## A-Weight: Direct Authorship Evidence

- **AI in the Author or Committer line.** Claude Code on the web commits with
  `Author: Claude <noreply@anthropic.com>` by default; `copilot-swe-agent[bot]` authors
  commits on its PR branches; Aider, Devin, Codex, Gemini CLI similarly surface bot
  identities. An AI named as author of a commit is direct evidence the commit's diff is
  machine-generated.
- **Co-authored-by trailers naming an AI.** `Co-authored-by: Claude <noreply@anthropic.com>`,
  `Co-authored-by: Copilot`, `Co-authored-by: Devin`. Documented rates:
  - Claude Code auto-adds its trailer to ~80% of assisted commits (Kraishan 2025); the only
    documented opt-out is setting `"attribution": {"commit": "", "pr": ""}` in
    `.claude/settings.json`
  - ~9% of Copilot-assisted squash merges carry Copilot trailers, often 15-45 per merge
  - Scale evidence: Quispe (Caltech 2026) harvested 7,786,771 Claude-co-authored commits from
    GitHub public API for Jan 2025 - Jan 2026; botcommits.dev's GH Archive/BigQuery series
    independently sums to 7.83M over the same window
  - Single-channel detection undercounts Claude Code usage by ~30x at project level
    (Khosravani & Mockus 2026) — absence of trailers is NOT evidence of human authorship
- **Model-slug trailers.** `Claude Sonnet 4.6`, version-stamped trailer names: timestamp the
  adoption era.

## B-Weight: Agent Presence Artifacts

- Root or nested `CLAUDE.md` (Claude Code's own instruction file, loaded hierarchically up
  the directory tree); nested instances mean agents ran throughout the subtree
- `AGENTS.md` (the shared standard read by Codex-style tools, Copilot, Cursor; Claude reads
  it conditionally when no CLAUDE.md exists — its presence means multi-tool agent workflows)
- `.cursor/rules/*.mdc`, `.cursorrules`, `.aider*` (incl. history files), `GEMINI.md`,
  `.clinerules`, `.windsurfrules`, `.claude/` directory with `settings.json`
- Symbolic/sync bridges (`CLAUDE.md` containing an `@AGENTS.md` import) — evidence of
  disciplined multi-agent ops, i.e. heavy AI generation throughput

## B-Weight: Git Behavior Patterns

- "Generated with Claude Code" / emoji-robot-wizard PR footers
- Machine-cadence commit/PR bursts: dozens of commits or PR merges in intervals no human
  sustains, especially with uniform message format
- Bot-owned head branches (`copilot/*`, `claude/*`, `devin/*`) merged by humans

## C-Weight: Textual and Structural Artifacts

- "Generated by Copilot"-style comments; docstring boilerplate uniformity across era-mixed
  code; whole-subtree idiom flips at a single commit boundary
- LICENSE added late to a single-contributor repo with no contributor-agreement history (the
  "license as decoration" tell)
- Output-growth discontinuity after a visible tooling adoption commit (added CLAUDE.md, added
  .cursorrules)

## Absence of Indicators Means Nothing

No registry of AI-generated code exists; tools can and do suppress trailers; Cursor adds
nothing by default. Absence reduces your presumption strength to the repo's normal license
caution — it never converts an AI-contaminated repo into a proven human one.

## Scanning One-Liner Library

    # trailer + author scan
    git log --all --no-merges --format='%aN|%aE|%GS' | sort | uniq -c | sort -rn | head -40
    grep -rEi 'generated by|written with (copilot|claude)' --include='*.{py,js,ts,go,rb,php}' .
    # era boundary detection: stylistic churn per release tag
    git log --since=2024-01-01 --format='%ad|%aN' --date=short | awk -F'|' '{print substr($1,1,7)"|"$2}'       | sort | uniq -c
