# Changelog

## [1.0.0] - 2026-11-27

### Added

- First public source release with 90 agent skills across 12 ad platforms and 183 behavior eval cases.
- Local read-only MCP with campaign inventory, setup guidance, and a credential-free skill catalog.
- Skills CLI commands for listing, installing, and selecting skills.
- Accessibility and contributor guides, with a private vulnerability reporting form for repositories where GitHub private reporting is enabled.
- GitHub Actions validation for the skill collection and the local MCP.

### Changed

- Root agent instructions link directly to all twelve platform READMEs and document the checks to run for each type of change.
