# Contributors

Ad Skill Jam is a VRIL LABS project. We welcome contributions to the skills, eval cases, MCP tools, and documentation. See the [contribution guide](CONTRIBUTING.md).

GitHub records commit contributors in **Insights → Contributors**. The [source provenance](ad-skill-jam/_shared/provenance/SOURCES.md) credits upstream projects whose work informed the packs. The [README](README.md) lists provider icon sources under **Artwork credits**.
