# YouTube Ads API ledger

Verified on 2026-11-26 against [Google Ads video guidance](https://developers.google.com/google-ads/api/docs/video/overview).

- For Demand Gen surface reporting select ad_network_type with ad_sub_network_type. Filter or label non-YouTube inventory. [Demand Gen reporting](https://developers.google.com/google-ads/api/docs/demand-gen/reporting)
