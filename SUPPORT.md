# Support

For setup help, start with the [MCP guide](ad-skill-jam/mcp/README.md). For questions about a platform workflow, open its [skill index](ad-skill-jam/README.md).

Ask setup and usage questions in [GitHub Discussions](https://github.com/VRIL-LABS/ad-skill-jam/discussions). Use the [issue forms](https://github.com/VRIL-LABS/ad-skill-jam/issues/new/choose) for reproducible bugs and feature requests. Include the affected pack or tool, relevant runtime versions, and redacted output. Report suspected vulnerabilities through [SECURITY.md](SECURITY.md).
