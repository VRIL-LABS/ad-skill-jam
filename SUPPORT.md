# Support

For setup help, start with the [MCP guide](ad-skill-jam/mcp/README.md). For questions about a platform workflow, open its [skill index](ad-skill-jam/README.md).

For a reproducible bug or a feature request, use this repository's **Issues** tab. Include the affected pack or tool, relevant runtime versions, and redacted output. Report suspected vulnerabilities through [SECURITY.md](SECURITY.md).
