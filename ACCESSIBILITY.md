# Accessibility

Ad Skill Jam’s primary interfaces are GitHub-rendered Markdown and a local command-line MCP server. The documentation uses descriptive headings and text links for platform navigation. The README artwork has a text alternative and respects reduced-motion preferences. Platform tiles include names as well as icons.

## Review documentation changes

For visual changes, check link names, keyboard navigation, narrow layouts, and both GitHub themes. Put task instructions and provider names in readable text so readers can use the guides when images are hidden. For screenshots or diagrams that carry information, include a text alternative.

## Report a barrier

Use the repository’s **Issues** tab and choose **Bug report**. Include the affected file or tool, the task you tried, and the browser, client, or assistive technology involved. Add any details that show where you got stuck. Follow the [support guide](SUPPORT.md) for help with setup.
